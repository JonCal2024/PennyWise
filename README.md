# PennyWise
PennyWise is a budget tracking web application designed to simplify personal finance management.

## Key Features
- Budget Planning: Set and manage budgets for various spending categories.
- Expense Tracking: Easily log and categorize daily expenses for better financial transparency.

## Technical Stack
- Backend: Developed using Java with Spring Boot to handle business logic and API endpoints.
- Frontend: Coded in JavaScript, offering a responsive user interface.
- Database: Powered by MongoDB, providing flexible and efficient data storage for users, budgets, and expenses.
- API Communication: Implements a REST API for secure communication between the frontend and backend.
